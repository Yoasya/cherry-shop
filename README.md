# cherry-shop

Учебный проект магазина вишни, созданный в рамках прохождения практики.

## Технологический стек
Frontend: HTML5, CSS3, JavaScript (Native).  
Хранение данных: LocalStorage (для работы корзины).  

## Основные фичи
Темная/светлая темы: Реализована смена темы оформления через JS.  
Каталог: Страницы с описанием различных сортов вишни.  
Система корзины: Добавление товаров и сохранение состояния при перезагрузке страницы.  

## Известные баги
Браузерная совместимость: В Firefox корзина может вести себя непредсказуемо (иногда она живет своей жизнью и отказывается корректно обрабатывать данные из LocalStorage).

## Структура проекта
index.html - главная страница.  
pics/ - папка с сочными изображениями ягод.  
styles.css - все стили и логика темной темы.
