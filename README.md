# CHERRY?

Учебный интернет-магазин вишни и черешни. Проект переработан как портфолио-кейс: обновлён интерфейс, упрощена навигация, добавлена мобильная версия, а повторяющиеся страницы товаров заменены одной динамической страницей.

## Что изменено

- полный редизайн главной страницы;
- каталог с DOM-рендерингом, фильтрацией и сортировкой;
- единая `product.html?id=...` вместо отдельных HTML-файлов на каждый сорт;
- корзина на `localStorage` с изменением количества и пересчётом суммы;
- светлая и тёмная темы с плавными переходами;
- адаптивная навигация и мобильные состояния;
- оптимизация изображений в WebP;
- lazy loading для изображений ниже первого экрана;
- более семантичная разметка и focus/hover состояния.
